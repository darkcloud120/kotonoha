更新：將此 ZIP 內全部檔案覆蓋到原有 GitHub Pages Repository（包含 rebuild.js），不需要更新 Chrome 擴充功能、Android APK 或 Cloudflare Worker。重新整理即可。

- 標題解析：歌手別名、Lyric Video、original、cover、feat. 與多語名稱清理；加入 Sukidakara / 好きだから。等已知歌名。KING、フォニイ、Henceforth 已知原唱優先（仍保留同名歧義手動選擇）。舊的自動匹配快取版本更新，使用者手動配對保留。
- 搜尋：首輪最多兩個請求；找到高可信度結果可提前結束；遇 HTTP 429 尊重 Retry-After 或冷卻 60 秒，不繼續集中呼叫 LRCLIB。假名對照會重用近期搜尋結果。實際 API 速度及收錄不保證。
- 假名：採用相符歌詞自帶標註，合併可比對的其他曲庫版本並保留手動讀音；加上七変化規則。移除付費 AI 校讀按鈕及舊 AI 猜測讀音的套用。UtaTen 沒有在此版直接爬取：可開啟參考連結，或匯入自己有權使用的 ruby / 括號讀音。僅覆蓋讀音，不改原始時間軸。資料來源仍可能有誤。
- 重製這首：閱讀設定 > 顯示選項 > 重製這首。需要已設定的私人 Worker；確認後重新搜尋、強制重新翻譯（計費）、重新找假名。搜尋或翻譯失敗不主動刪除舊紀錄；不同歌詞原文需再次確認，原本不相容的時間軸不套用。成功後更新當前歌曲的本機歌曲庫、匹配及翻譯，保留收藏和手動修正。雲端 KV 依精確原文儲存，新翻譯若寫入成功即取代同一原文的雲端內容；不同原文保留舊快取。其他裝置重新載入時背景讀雲端，保留獨立手動翻譯。假名修正與收藏仍是本機資料。
- 測試：Node 語法、12 組標題、5 組選曲及歧義、模擬快速回應和 429 冷卻通過。Chromium 頁面載入受環境政策阻擋；未驗證真實 API、重製 UI 或真機。

## RC6（網站單獨更新）
- 網站完整覆蓋，包含新增的 `kana-rc6.js`；沿用 RC5 Chrome 擴充功能、Android APK 和 RC4 Worker。不更換歌詞時間軸、翻譯快取或播放器協定。
- 假名優先：手動逐句修正 → 已核對的歌曲限定讀音 → 歌詞原有括號讀音 → 其他歌詞版本讀音 → 常用詞規則 → 已有 AI 校讀 → 完整句子 Kuromoji。單獨一人、二人依常用讀法，排除一人称、一人前、十一人等；特殊讀音仍需來源或人工確認。
- 每首有漢字的已載入歌曲在背景查 LRCLIB，必要時查原有 LiriQo API。對照至少 55% 的不同原句且至少三句（短歌則需全部），僅套用相同句子明示的括號假名；不更換原文或時間戳。搜尋結果在本次開頁暫存，重開可重新查。UtaTen 提供手動開啟連結，未做自動爬取；可匯入有權使用的括號讀音參考版本，另存在本機。不呼叫 OpenAI。API 收錄與可用性未保證。
- 閱讀設定的三個翻譯模式改為獨立按鈕，單首翻譯保留在外面；重新翻譯、假名校讀等放進可展開選項。純歌詞模式保留設定鈕，展開浮層可調字體與假名。
- 原先 sessionStorage 只保存分頁生命週期。請再輸入私人存取密碼、勾選「在此裝置記住私人密碼（重開仍保留）」並按儲存；新設定使用 localStorage，不會存到雲端或匯出備份。取消勾選會清除持久設定，按停止並清除密碼則也移除本次連線。只在自己的可信裝置使用；本機儲存並非加密保險庫，清除網站資料或卸載 App 仍會移除。
- 新增程式已通過 Node 語法檢查，以及讀音規則、例外、同句比對、矛盾讀音排除、重疊修正與模擬儲存/重開/清除測試。Chromium 實際頁面載入被環境阻擋；外部 API、手機及電腦實際 UI 需驗證。
