# ことのは 1.0 RC1

從 v0.6 完整更新。將本 ZIP 的所有檔案解壓縮後上傳至原本 GitHub Pages repository 根目錄（不要多包一層資料夾）。重新整理確認頁首 1.0 RC1。保留同網址可繼續讀取舊版 localStorage。原本 v0.6 Worker、KV、API 設定不用變更。若仍在 v0.4.1 Worker，可使用翻譯但無跨裝置快取／AI 假名校讀；依 v0.6 的部署說明升級。

## 功能
- 原本的多來源歌詞、假名、三種翻譯模式、手動／AI 校讀、KV 翻譯同步。
- 愛心收藏、歌曲庫（近 150 首非收藏項目上限策略，收藏優先保留；受 localStorage 容量限制）、已翻譯篩選。從收藏開歌會退出自動跟隨，可重新勾選。
- 純歌詞模式（歌名旁 ⛶，退出按鈕或 Esc），儲存字體／假名／自動捲動偏好。
- 電腦擴充新版可讀 YouTube 一般 watch 頁。有效影片 ID 時顯示 YouTube 縮圖，嘗試擷取主色；若跨來源不允許讀像素，使用影片 ID 生成的配色。Android 媒體 ID 若不是影片 ID 則使用預設圖示。
- 翻唱 / 播放版本設定 → 逐句對時。先將播放器移到開頭，按「逐句對時」，每次唱到下一句時按「記錄下一句」，或鍵盤焦點不在輸入／按鈕時按空白。包括空白間奏。可復原、取消；全部記錄後儲存。重新切歌不會覆寫未完成的對時。
- 歌曲庫 → 備份與還原，可匯出／匯入本機 JSON。排除 AI URL、密碼、sessionStorage。備份含歌詞、翻譯與修正，僅供私人備份。Android WebView 下載功能可能不支援，先以電腦備份；手機已有 AI 翻譯請先上傳雲端。

## 給朋友使用
公開網站可直接打開；朋友安裝擴充或 Android APK 後即可使用同步。不要傳送自己的 API 金鑰或私人 Worker ACCESS_TOKEN，也不要把這些放在 GitHub。朋友未設定自己的後端時只有本機／免費功能，不能讀取你的雲端翻譯庫或使用付費 AI。使用第三方歌詞來源應遵守授權與服務條款，不公開轉載歌詞庫。

## 測試與限制
JavaScript 語法檢查、模擬 YouTube DOM、以 Chromium 載入實際程式搭配模擬歌詞 API／儲存的 UI 測試已通過。真正的網頁導航受測試環境限制，實際 YouTube DOM、跨裝置同步、外部假名字典和 Android 真機仍待驗證。收藏、手動假名、時間軸為本機資料，只有完整 AI 翻譯沿用 KV 同步。非音樂影片可能嘗試搜尋歌詞；無法保證所有影片標題或廣告辨識。沒有可靠時間戳的歌曲需自行對時，不猜時間。多個播放器同時播放時可能選錯，請暫停另一個。
