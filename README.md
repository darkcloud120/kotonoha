- 歌詞顯示與翻譯設定合併至閱讀區上方，顯示選項可展開；重新翻譯需確認費用。

- 影片標題解析修正（Cotton Days）；若原先記住錯誤歌詞，按重新搜尋再手動選擇以更新對應。

- 雲端重翻後其他裝置已有本機舊翻譯可能仍沿用舊版；目前不自動覆蓋本機翻譯。
RC5 新增：在已連線且支援控制的播放器上，播放／暫停、±5 秒、歸零、拖曳 0.1 秒步進的進度條；拖曳期間避免同步覆蓋滑桿，放開才送出跳轉。歸零在同步模式只跳到 0，不改變播放狀態。需 RC5 擴充功能或 Android RC5；舊版點句跳轉仍相容。拒絕 GitHub Pages 作為 AI Worker 網址，非 JSON 回應顯示清楚錯誤。Worker 不需更新，原 KV 與本機快取保留。
測試：JS 語法、網站控制及兩個播放器的模擬指令測試通過；實際 Chromium 網頁載入遭環境封鎖，未驗證真實瀏覽器拖曳、YouTube 播放器、Android 編譯與真機、雲端 KV。

## RC6（網站單獨更新）
- 網站完整覆蓋，包含新增的 `kana-rc6.js`；沿用 RC5 Chrome 擴充功能、Android APK 和 RC4 Worker。不更換歌詞時間軸、翻譯快取或播放器協定。
- 假名優先：手動逐句修正 → 已核對的歌曲限定讀音 → 歌詞原有括號讀音 → 其他歌詞版本讀音 → 常用詞規則 → 已有 AI 校讀 → 完整句子 Kuromoji。單獨一人、二人依常用讀法，排除一人称、一人前、十一人等；特殊讀音仍需來源或人工確認。
- 每首有漢字的已載入歌曲在背景查 LRCLIB，必要時查原有 LiriQo API。對照至少 55% 的不同原句且至少三句（短歌則需全部），僅套用相同句子明示的括號假名；不更換原文或時間戳。搜尋結果在本次開頁暫存，重開可重新查。UtaTen 提供手動開啟連結，未做自動爬取；可匯入有權使用的括號讀音參考版本，另存在本機。不呼叫 OpenAI。API 收錄與可用性未保證。
- 閱讀設定的三個翻譯模式改為獨立按鈕，單首翻譯保留在外面；重新翻譯、假名校讀等放進可展開選項。純歌詞模式保留設定鈕，展開浮層可調字體與假名。
- 原先 sessionStorage 只保存分頁生命週期。請再輸入私人存取密碼、勾選「在此裝置記住私人密碼（重開仍保留）」並按儲存；新設定使用 localStorage，不會存到雲端或匯出備份。取消勾選會清除持久設定，按停止並清除密碼則也移除本次連線。只在自己的可信裝置使用；本機儲存並非加密保險庫，清除網站資料或卸載 App 仍會移除。
- 新增程式已通過 Node 語法檢查，以及讀音規則、例外、同句比對、矛盾讀音排除、重疊修正與模擬儲存/重開/清除測試。Chromium 實際頁面載入被環境阻擋；外部 API、手機及電腦實際 UI 需驗證。
